## 📌 About The Project
This is my very first complete Data Science project. 

The code you see here is my initial and raw approach to data analysis. I left everything exactly as I wrote it the first time around, along with all my original comments. It is not pretty, but that is the point. I want this repository to document my real thought process and serve as a starting point before I apply proper software engineering patterns.

## 🛠️ What's Inside Right Now
*   **Manual Data Imputation:** Handling missing values completely from scratch to understand how the data actually works.
*   **Custom Feature Engineering:** Creating specific age group metrics and converting text categories into numbers.
*   **Baseline Model:** Training a simple Random Forest that achieved around 82% accuracy on the training data and 77,99% on the Kaggle test set.
